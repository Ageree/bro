# jev-lab: замеры jev-ultrafast на поручениях Бро

Стенд, на котором доработан jev-ultrafast из движка `jev-then-agent`
(`browser-vm/image/jev-ultrafast.patch`). Гоняет jev с моделью решений TypeSafe
Jev на задачах Бро и пишет полную трассу каждого шага: что предложено, что
выбрано, с какой уверенностью, что сделано и изменило ли это страницу. Успех
проверяется по итоговой странице (адрес, заголовок, видимый текст), а не по
`DONE` самого jev. Скрипты — тестовый стенд, не код Бро.

| Файл                | Что делает                                                                                     |
| ------------------- | ---------------------------------------------------------------------------------------------- |
| `lab.py`            | Chrome на своём порту, сервер фикстур, прогон задач и наборов, таблица успехов, пересчёт       |
| `tasks.py`          | Задачи и их проверки: `dev`, `heldout`, `fresh`, `env`, фикстуры из `fixtures/manifest.json`   |
| `trace_run.py`      | Один прогон jev с трассой; мягкий дедлайн за 10 с до жёсткого, чтобы трасса не терялась        |
| `fixtures/`         | 14 локальных страниц, по одному сложному виджету; успех — заголовок, начинающийся с `PASS`     |
| `fixture_check.py`  | Проверка логики PASS: верные действия доходят до PASS, неверные и неполные — нет (Playwright)  |
| `exec_probe.py`     | Действия исполнителем jev по подписи элемента, без модели: отличить сбой наблюдения от решения |
| `probe_failures.py` | Какие запросы страницы Chrome не загрузил (прокси, ORB): поломка стенда, а не jev              |

## Наборы задач

- `dev` — на них искали причины и проверяли доработки: Википедия (поиск,
  статья дня), Яндекс Расписания (Сапсан с датой и вечерним фильтром, клик по
  популярному направлению), ВкусВилл.
- `heldout` — похожие виджеты на других сайтах (Туту, Авиасейлс, hh.ru, Kayak,
  Airbnb, Островок, Афиша, Ситилинк); разработчики их не видели, только замер.
- `fresh` — второй отложенный набор (OneTwoTrip, Победа, Trainline, Amtrak,
  Суточно, Лабиринт, М.Видео, Авто.ру, Детский мир, Кинопоиск) для финального
  замера после ревью.
- `env` — Google Flights: из облачной сессии Claude не проходит ни при каком jev
  (см. ниже), оставлен для прогона на VM.
- фикстуры (`fx_*`) — портал-комбобокс, автодополнение с обязательным выбором
  подсказки, ARIA-календарь, календарь на `div` без ролей, поиск с анимированным
  плейсхолдером и отправкой по Enter, форма в iframe, форма в shadow DOM, список
  с прокруткой внутри контейнера, оверлей согласия, фильтры и свой «Сортировать»,
  чипы популярных маршрутов, степперы гостей, подсказки без ARIA, чекбоксы за
  `<label for>`; плюс календарь с делегированным кликом, поле-«чипы», popunder (результаты в
  новой вкладке) и диалог фильтров, который надо применить.

Все задачи только на чтение: поиск и фильтры, без входа, заказов и оплаты.

## Запуск

```bash
# jev: upstream на закреплённом коммите и патч Бро (без патча — исходный jev для сравнения)
git clone https://github.com/browser-use/jev-ultrafast.git .jev && git -C .jev checkout -q 1231850
git -C .jev apply ../../browser-vm/image/jev-ultrafast.patch && (cd .jev && uv sync)

export TYPESAFE_API_KEY=… OPENROUTER_API_KEY=…   # Jev и текстовый helper (inception/mercury-2.5)
python3 lab.py run --jev .jev --port 9231 --tag mine --set dev --rounds 2
LAB_HEADED=1 python3 lab.py run --jev .jev --port 9232 --tag mine-headed --set fixture   # Chrome с окном в Xvfb, как на VM
python3 lab.py table runs/mine.jsonl runs/mine-headed.jsonl
```

`fixture_check.py` запускайте из venv с Playwright (`uv pip install playwright`,
без `playwright install`: он подключается к Chrome стенда по CDP) и с
`JEV_DIR` на исходном jev (сценарии есть для первых 14 фикстур) — он ещё проверяет, что каждая ловушка действительно
прячет элементы от исходного снимка страницы.

У каждого параллельного прогона — свой `--port`: свой Chrome, профиль и демон
browser-harness (`BU_NAME`). Режим с окном (`LAB_HEADED=1`) ближе к VM Бро
(Chrome в Xvfb); headless отличается анимациями фоновых вкладок. Каждое решение
TypeSafe платное: наборы гоняйте по 1–2 круга. `LAB_CLEAN_PROFILE=1` начинает каждый прогон
с нового профиля Chrome: иначе прогон наследует заполненные формы и «продолжить поиск» прошлого.

## Облачная сессия Claude

- Прокси сессии подменяет TLS: Chrome доверяет ему, только когда CA прокси лежит
  в `~/.pki/nssdb` (`apt-get install libnss3-tools`, затем
  `certutil -A -n ccr-agent-proxy -t "C,," -i /root/.ccr/agent-proxy-ca.crt -d sql:$HOME/.pki/nssdb`).
  Адрес прокси `lab.py` берёт из `HTTPS_PROXY`.
- Прокси отвечает Chrome 403 на пути с `;` (ленивые модули Google на gstatic):
  виджеты Google Flights не оживают, поэтому Flights — набор `env`. Проверка —
  `probe_failures.py`.
- IP сессии в США: Яндекс показывает «Вашингтон», WB, Ozon, 2ГИС, РЖД и часть
  выдачи Avito сессию не пускают.
- `OPENROUTER_API_KEY` облачной среды приходит с переводом строки: `lab.py`
  убирает пробельные символы из ключей.

Итоги замеров — `docs/browser-cloud-migration.md`, раздел про jev-ultrafast.
