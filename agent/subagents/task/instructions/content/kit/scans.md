- Архив: `brokit zip unpack`, `brokit files survey`, `look` только для фото и сканов без текста, `brokit zip pack`.
- Фото страниц, чеков и документов в скан или PDF — только `brokit img scan` (перспективу он считает гомографией; своё выпрямление строки искривит), лимит веса — `--max-mb`; так же, если задача велит вставить фото как есть или «по центру листа». Несколько фото в один PDF «по порядку» без порядка от человека: страницы одного документа — по номерам, отдельные чеки и билеты — по дате и времени на них, а не по именам файлов.
- Фото на документы (паспорт, виза, пропуск, 3×4) и лист для печати — только `brokit img idphoto` (`--size`, `--sheet 10x15`), не своим кодом: он выпрямляет голову по глазам и ставит её размер по нормам; проверь `roll_deg` ≈ 0 (None — глаза на результате не найдены: проверь линию глаз через `look`) и `head_mm`.
