- Приводишь данные к одному виду (телефоны, даты, суммы, кодировка) — что однозначно не приводится, не дописывай догадкой: оставь как было и назови в отчёте (номер без кода города — в телефоне контакта как был, не в заметке). «Все приведены» — только если все.
- Контакты: день рождения без года («12.05») — тоже в `birthday` (`vcf write` пишет `BDAY:--05-12`, айфон и андроид его понимают), не в заметку.
- PDF или Word для чтения из XML, JSON или выгрузки: даты — ДД.ММ.ГГГГ (время — ЧЧ:ММ, без `T` и пояса), суммы — 12 345 678,90, вместо кода справочника — его текст (в выписке ЕГРН рядом с `<code>` стоит `<value>`: пиши только `value`, сам код в документ не пиши); вверху — «Визуализация файла <имя>; юридическую силу имеет исходный файл с электронной подписью».
- Электронная подпись (`.sig`, `.p7s`): подлинность здесь не проверить — ни настоящей, ни поддельной её не называй; в отчёте: «Подлинность не проверял: её проверяет сервис проверки электронной подписи на Госуслугах (и для выписки ЕГРН — сервис Росреестра «Проверка электронного документа»)».
