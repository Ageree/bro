# Goal: Bro 2.0 — проактивность + платная бета

Bro (личный iMessage-консьерж: eve + Convex + Inkbox + Browser Use + Composio)
становится проактивным агентом и платной бетой на ~100 человек.

## Что строим (утверждено оператором 2026-08-27)

Один архитектурный примитив — **Convex wakeups**: таблица `wakeups`
(tenant, at, kind, payload) + cron-диспетчер, который будит eve-агента
HTTP-вызовом «фонового хода»; агент решает и пишет в iMessage через
существующий `sendBlueIMessage`. На этом примитиве четыре сценария:

1. **Доводит дела до конца** — `browser_task` при активном джобе сам ставит
   wakeup «проверь через N минут»; когда джоб завершён, Bro пишет ПЕРВЫМ
   с результатами (сейчас ждёт пинга «ну что»).
2. **Напоминания/отложенные** — тулы `schedule_wakeup` / `cancel_wakeup`
   («напомни в пятницу», «напиши маме за день до ДР»).
3. **Утренний бриф** — ежедневный wakeup per tenant (таймзона, по умолчанию
   Europe/Moscow): почта/встречи (если подключён Composio), статус дел,
   напоминания. Одно сообщение, без спама.
4. **Сторожа (watchers)** — периодические wakeup'ы «проверь X» (Gmail,
   календарь, цена товара); писать только если есть новое.

Плюс продукт: **платная бета ~100** — ЮKassa (разовые платежи «месяц» для
беты), webhook → `tenants.paidUntil`, лимиты per tenant (сообщения/день,
браузер-джобы/месяц), мягкий paywall в iMessage, кап identity поднят.

## Ограничения

- Ponytail: минимальный код, стдлиб/платформа прежде всего, Convex уже умеет
  крон/шедулинг — не заводить новых рантаймов и зависимостей без нужды.
- КОД ПИШУТ headless grok-сессии (`grok -p ... --permission-mode acceptEdits`),
  Lead (Claude) планирует, дробит на пакеты, верифицирует и коммитит.
- Не трогать: `vendor/`, `convex/_generated/`, существующий формат ответов
  iMessage (`imessage-text.ts`), `index.html` кроме секции оплаты.
- Секреты только в env; ЮKassa-ключей пока нет — биллинг строится за env-гейтом
  и проверяется структурно + моками, живой платёж — когда оператор даст ключи.
- Проактивные отправки консервативны: никогда не слать, если нечего сказать;
  сторожа и бриф молчат при пустом дельта-состоянии.

## Спайк-предпосылка (сделать ПЕРВОЙ)

Проверить, что Inkbox доставляет outbound iMessage в существующий тред спустя
часы после последнего входящего (проактивность без входящего). Если есть кап —
зафиксировать в events и адаптировать дизайн (например, деградация в
«отвечаем на следующий входящий»).
