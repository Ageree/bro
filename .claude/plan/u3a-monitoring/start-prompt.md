# U3a. Мониторинг: журнал ходов, тревога о сбое хода, утренняя сводка

Ты делаешь только этот юнит. Сначала — `.claude/plan/PROTOCOL.md`.

## Зачем
Владелец открывает бету примерно для 10 человек и хочет видеть всё, что у них
происходит. Сейчас он видит только тревоги о балансе или пуле и расход по месяцу
(`/api/usage-costs`). Списка ходов нет, о сбое хода знает лишь сам человек.
Владелец решил (12.10): хранить для него и тексты переписки. Согласие людей даёт
юнит U5 (условия беты, срок хранения — 30 дней). Ограничений и лимитов на
пользователей не вводим.

## Что сделать
1. Таблица ходов (метаданные): workspace, user, канал (telegram/imessage/web/
   фон/расписание), id сессии и хода eve, вид хода (человек, отчёт браузера,
   расписание, task), время начала и конца, длительность, число шагов, имена
   вызванных инструментов, исход (completed/failed) и код ошибки, стоимость в
   рублях (из `usage_costs` или подсчётом в хуке). Пиши её хуками рядом с
   `agent/hooks/usage-costs.ts` и `agent/hooks/evlog.ts` (`turn.started`,
   `turn.completed`, `turn.failed`, `actions.requested`). Хук не должен ронять
   и тормозить ход: сбой записи — `console.warn` без текста.
2. Тексты для владельца под флагом `OWNER_TRANSCRIPTS=on|off` (по умолчанию
   off; включит координатор после выката U5). Что хранить: слова человека,
   текст ответов Бро (`send_message` и финальный текст), краткие аргументы и
   результаты инструментов (обрезка, например 2 КБ). Перед записью вырезать
   коды, пароли, номера карт и документов: переиспользуй то, что уже есть
   (`agent/hooks/conversation-log.ts`, `agent/lib/privacy/document-numbers.ts`,
   фильтр секретов из PR 295). Не путай с `conversation_log` пилота
   `CROSS_CHANNEL` и не ломай его. Срок хранения — env (по умолчанию 30 дней),
   удаление старого — расписанием.
3. Тревога владельцу о сбое хода человека — через `alertOwner`
   (`agent/lib/owner-alert.ts`): workspace (имя или телефон), канал, код
   ошибки, время. Без текста сообщений. Дедупликация по workspace и коду,
   чтобы при 402 RouterAI не пришло 10 одинаковых.
4. Утренняя сводка владельцу в Telegram (тем же `alertOwner` или напрямую):
   за сутки — активные люди, ходы, сбои по кодам, расход в рублях по людям,
   новые регистрации. Время — env, по умолчанию 09:00 МСК.
5. Сервис чтения для будущей страницы владельца (U3b): функции в
   `db/services/…`: список пользователей с последней активностью и расходом;
   ходы пользователя за период; текст хода. Страницу не делай — это U3b.

## Ловушки
- Хуки eve: порядок и события — `docs/dev-notes.md`, разделы «eve» и «Ход и
  доставка». Ход может быть продолжен после рестарта, а id хода повторяется в
  преемнике сессии с `turn_0`: ключ — сессия + ход + время начала.
- Метки для сообщений в Telegram делает U4 (`#alert`, `#bug`), он правит
  `owner-alert.ts`. Ты этот файл не трогай, только зови `alertOwner`.
- Миграцию генерируй поверх свежего `bro-next`: U4 тоже добавляет миграцию.

## Параллельно идут

## Проверка
Юнит-тесты хуков (запись, сбой записи не роняет ход, вырезание секретов,
флаг off не пишет тексты), PGlite-тест сервиса, `pnpm check`, `pnpm build`,
`pnpm build:eve`. Подходящая модель: сильная, это схема данных и приватность.
