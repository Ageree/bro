# Единица «yandex»: операции Яндекса на чтение

Ветка: `claude/speed3-yandex` от `origin/bro-next`. Бюджет: 150 ₽.
Сначала прочитай `PROTOCOL.md`:
`git show origin/claude/speed2-plan:.claude/plan/speed3/PROTOCOL.md`.

## Задача — только эта

Ускорить операции Яндекса на чтение: перевести оставшиеся на лёгкую страницу, где ответ
тот же, и дать цифры для включения `YANDEX_DIRECT` всем.

## Что известно (`docs/yandex-api/speed.md`, замер 12.10)

- Время уходит на загрузку тяжёлой страницы сайта, а не на вкладку (60–130 мс).
- Лёгкая страница (`robots.txt` своего origin) уже стоит у `afisha.search`,
  `market.search`, `food.eda_search`, Go и чтений Лавки. Остальные операции Афиши и
  Маркета работают на тяжёлой странице.
- Карты грузят страницу только до `interactive`, но всё равно занимают 8,9 с (контекст —
  из JSON страницы `/maps/`, 8,9 МБ); Афиша в журнале прода — 25,7 с.
- `afisha.search` с сервера без браузера — флаг `YANDEX_DIRECT_WORKSPACES` (нужен и
  `YANDEX_API_WORKSPACES`), сейчас выключен. С адреса Selectel Афиша отвечала 200 за
  0,14 с. Любой отказ — откат во вкладку и пауза 10 минут.
- Маркет с адреса сервера отвечает редиректом. Вариант «cookies профиля на сервер»
  отвергнут (dev-notes, «Скорость операций Яндекса»).
- Код: `agent/lib/yandex/operations.ts`, `registry.ts`, `transport.ts`,
  `agent/lib/yandex/<сервис>/`, инструмент `agent/tools/yandex.ts`.

## Что сделать

1. Замерь все операции на чтение («до»):
   - строки `[yandex] call` (`tabMs`, `callMs`) и `ai.tools[].durationMs` в журнале eve;
   - прямой вызов: `scripts/cloudru-app-host/yandex-probe.py bro-app-sel-2 spec.json` с
     `{workspace, op, args}` (режим `page` — запросы страницы с телами). Id воркспейса
     владельца — значение `FLASH_SEARCH_WORKSPACES` в
     `/root/.bro-app-host-selectel/env/prod.json` (после `state restore`; сам файл не
     печатай, возьми одно поле). Каждую операцию — не меньше 3 раз.
     Черновой PR сразу после «до».
2. Переведи на лёгкую страницу каждую операцию, где ответ тот же (сравни ответы
   побайтно или по полям — в PR только итог «совпало/нет»). Карты: проверь, можно ли
   взять контекст легче, чем 8,9 МБ `/maps/`.
3. Проверь `YANDEX_DIRECT` на проде пробой с адреса VM (ops-скрипт или probe): ответы
   200, время, капча — 10+ вызовов в разное время. Дай цифры для решения «включить
   всем»; включает координатор.
4. Цифры «до» → «после» (пробой на неслитой ветке нельзя — после выката; до выката —
   замер страницы `page`-режимом пробы), готовая команда «после».
