# План: API сервисов Яндекса для Бро

Цель (владелец, 10.10): Бро уже вошёл в сервисы Яндекса аккаунтом владельца в
своём браузере пула. Обернуть сервисы в API, чтобы Бро пользовался ими за
секунды, а не минутами шагов `browser_task`.

Решение координатора: запрос делает сама страница Яндекса во вкладке браузера
пула (`fetch` из `Runtime.evaluate` во вкладке keep-alive, как
`createBrowserVmBrowser` в `agent/lib/browser-vm/runs.ts`). Cookies не покидают
песочницу, CSRF и адрес выхода — настоящие, код worker не меняется. Набор
запросов фиксирован кодом (операции), модель URL не задаёт. Флаг
`YANDEX_API_WORKSPACES`: сначала воркспейс владельца.

Принятые по умолчанию ответы (владелец не возразил): сервисы — Маркет, Еда и
Лавка, Go (цена), Карты (организации, бронь на чтение), Афиша; инструмент
читает и меняет только корзину, оформление и оплата — за `browser_task` с «да»
человека; режим — до конца; журнал — этот файл и комментарии в PR.

## Единицы

| Единица            | Что                                                                  | Модель      | Зависит от     | Статус   |
| ------------------ | -------------------------------------------------------------------- | ----------- | -------------- | -------- |
| `base`             | Транспорт вкладки пула, инструмент `yandex`, флаг, операция `status` | Sonnet 5.5  | —              | запущена |
| `d-market`         | Разведка Маркета → `docs/yandex-api/market.md`                       | Sonnet 5.5  | —              | запущена |
| `d-food`           | Разведка Еды и Лавки → `docs/yandex-api/food.md`                     | Sonnet 5.5  | —              | запущена |
| `d-go-maps-afisha` | Разведка Go, Карт, Афиши                                             | Sonnet 5.5  | слот           | ждёт     |
| `i-<сервис>`       | Операции сервиса по спецификации                                     | Haiku 5.5   | `base` + `d-*` | ждёт     |
| live               | Выкат, флаг владельцу, живые проверки                                | координатор | всё            | ждёт     |

Параллельно — не больше 3 сессий; разведки делят один браузер, поэтому не
больше двух сразу.
