# Формат спецификации разведки (`docs/yandex-api/<сервис>.md`)

Спецификацию читает исполнитель на Haiku, который по ней пишет код операций, не
видя браузера. Пиши так, чтобы ему не пришлось ничего угадывать.

В начале: сервис, origin страницы, с которой делаются запросы (вкладка сначала
открывает её — какая самая лёгкая страница этого origin даёт рабочий
контекст: cookies, `sk`/CSRF, `window.__…` с токенами), сколько мс занимает её
загрузка, и как узнать «не вошёл» и «капча» (редирект на `passport.yandex.ru`,
`/showcaptcha`, поле в ответе).

Для каждой операции (`market.search`, `market.orders` …):

1. **Зачем человеку** — одна строка; чтение или запись.
2. **Запрос** — метод, URL, query/body с типами и допустимыми значениями,
   обязательные заголовки и откуда взять каждый токен (из HTML страницы —
   каким регулярным выражением или путём в `window`; из cookie, которую
   страница сама приложит, — тогда ничего делать не надо).
3. **JS** — работающее тело для `cdp.py eval` (async, `return …`), которое ты
   прогнал: принимает аргументы объектом `args` в начале (`const args = {...}`),
   возвращает уже **ужатый** результат — только поля, нужные человеку (название,
   цена, статус, дата, ссылка), не больше 10 элементов. Ужимание — часть
   операции: Бро платит за каждый токен ответа.
4. **Ответ** — схема ужатого результата (поля, типы, nullable) и одна
   синтетическая фикстура сырого ответа в `tests/fixtures/yandex/<сервис>/<операция>.json`
   (структура настоящая, значения выдуманы, лишнее можно срезать) — для
   юнит-теста разбора.
5. **Сбои** — что приходит при «не вошёл», капче, пустом результате,
   неверном аргументе; как отличить.
6. **Замер** — сколько мс занял запрос (3 прогона, медиана) поверх уже
   открытой страницы.
7. **Устойчивость** — что в запросе похоже на версию сборки или хэш (`r=`,
   `version`, persisted query id), откуда его брать заново, если поменяется.

В конце — что не удалось и почему, и что стоит сделать через `browser_task`
(оформление, оплата, то, что требует капчи или подтверждения).
