# U5. Тексты беты: что Бро говорит о данных, условия и согласие, знакомство

Ты делаешь только этот юнит. Сначала — `.claude/plan/PROTOCOL.md`.

## Зачем

Бета открыта для всех, у всех полный функционал (решение владельца 12.10).
Владелец будет видеть тексты переписки для отладки: юнит U3a хранит их 30
дней под флагом `OWNER_TRANSCRIPTS`. Флаг включат только после того, как
люди получат условия из этого юнита.

## Что сделать

1. `agent/lib/privacy/facts.ts`: Бро до сих пор говорит людям, что работает на
   Vercel, история лежит в Vercel Workflow, база — в Neon, модели — через
   Vercel AI Gateway. На самом деле: VM Selectel в России, managed PostgreSQL
   Selectel, S3 Selectel. Модели — через RouterAI (хосты DeepInfra, RunInfra
   для DeepSeek). Внешние сервисы по функциям: Composio (Google и
   приложения), ElevenLabs и Exolve (звонки), AgentMail (почта), Browser Use
   (поручения браузеру вне пула), Supermemory (если используется — проверь).
   Сверь каждый пункт с кодом и env, а не с этим списком. Обнови тест.
2. Страница `/privacy` (рядом с `app/(public)/oferta`): кто оператор (возьми
   из оферты), какие данные собираются, куда передаются (список из п. 1),
   срок хранения. Отдельным разделом «Бета»: на время беты владелец сервиса
   может читать переписку с Бро, чтобы находить и чинить ошибки; переписка
   для этого хранится 30 дней; коды и пароли вырезаются. Как удалить данные —
   написать владельцу (контакт возьми из оферты). Как сообщить об ошибке —
   бот `@<BUG_BOT_USERNAME>` (env из U4; без него строки нет). Оформление —
   примитивы `web/components/ui` и `type-*`, как у оферты.
3. `app/sign-in`: строка под формой «Продолжая, вы принимаете условия и
   политику конфиденциальности» со ссылками на `/oferta` и `/privacy`.
4. Знакомство (`first-contact`, `agent/instructions/content/role/interactive.md`
   и рядом): добавь, что это бета, ссылку на условия и `/privacy`, куда
   писать о багах. Убери обещание «почти любое дело» в пользу честного «многое
   умею, учусь». Проверь фразу про звонок «ИИ-помощником»: решение владельца
   — Бро не называет себя ИИ в приветствии звонка (`docs/dev-notes.md`).
   Ядро промпта ≤ 10 тыс. токенов (`tests/agent/skills/core.test.ts`): новые
   строки — за счёт других. Хэши промптов обнови по упавшему
   `tests/agent/skills/flag-off.test.ts`.
5. Веб-чат при сбое модели показывает по-английски «The model is temporarily
   unavailable» (`app/(authenticated)/chat/[sessionId]/_lib/turn-failure.ts`):
   сделай по-русски, в духе текстов Telegram (`agent/lib/delivery/fallback.ts`).
6. Колонка `workspaces.terms_accepted_at` не нужна: согласие — строкой при
   входе и в знакомстве. Если считаешь иначе, напиши в PR, не делай.

## Зависимости

Начинай после слияния U3a и U4 (возьми из их PR имена env и срок хранения).
Если чего-то не хватает — делай текст без этого и напиши в PR.

## Проверка

Тесты фактов, страниц (как у оферты), знакомства, `pnpm check`, `pnpm build`,
`pnpm build:eve`.

## Результат

PR в `bro-next`. В описании — тексты целиком, чтобы владелец прочитал их
до слияния.
