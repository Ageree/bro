# Задание 5: страницы одной категории не закрывают сайту поиск строкой

Ветка: `claude/site-category-pages`. Версия worker (если понадобится правка worker): `2026-10-27.3`.
Сначала прочитай `.claude/plan/cold-path/PROTOCOL.md` из этой же ветки (правила те же; основная ветка уже
содержит задания 1–3 — worker `2026-10-27.1`; задание 4 параллельно правит старт чтений в `worker.py`).

## Что видели (прод, 27.10, тестовый аккаунт, «угловой диван» на hoff.ru)

```
[site-api] left to the browser { chose: 'hoff.ru/nsk/catalog/gostinaya/divany/divany-uglovye/', filled: true,
  offered: [ 'hoff.ru/nsk/catalog/shkafy/', 'hoff.ru/nsk/catalog/gostinaya/divany/' ], reason: 'no_operation' }
```

У сайта сохранены лишь страницы конкретных категорий без места для слов поиска (выучены концом прошлых
поручений). Модель заполнения назвала страницу, которой нет среди предложенных, и Бро ушёл в браузер (55 с), а
поиск строкой сайта (`lookSite`, холодный путь) даже не пробовался: он идёт только у сайта без операций.
`carriesWords` (`agent/lib/browser-vm/site-ops/direct.ts`, задание 2) отсеивает лишь шаблоны с одним `%id%`;
литеральные страницы он пропускает намеренно — по одному шаблону их не отличить от `/hotel/russia/kazan/`.

## Что сделать

1. Бро: если ни одна из предложенных операций не подошла (`no_operation`, `address`, `fit`) и ни одна из операций
   сайта не может нести слова поиска (нет `%query%`/`%word%` в шаблоне), поиск идёт в холодный путь
   (`lookSite`: строка сайта, затем страница модели), как у сайта без операций, — в пределах того же пилота
   (`siteColdPilot`) и с теми же правилами `looked`. Сайт с настоящей операцией поиска (hh, ozon, wb, labirint,
   petrovich, kinopoisk, tutu, ostrovok, litres, youla — `known.ts`) остаётся как есть.
2. Worker: конец поручения не учит операцию из страницы одной категории, в адрес которой слова поручения не
   попали (как задание 2 сделало для взгляда: `site_words_placed`). Посмотри, где конец запуска отдаёт операции
   (`SiteTraffic.operations`, `site_rows_operations` в конце `run`), и отсекай там тем же правилом, если слова
   поручения известны; если нет — оставь как есть и напиши почему.

Проверка: тест Бро, который падал до правки (сайт только с литеральными страницами категорий → `lookSite`;
сайт с `%query%`-операцией → не идёт в холодный путь), и тест worker, если правишь его.
