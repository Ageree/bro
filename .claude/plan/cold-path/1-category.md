# Задание 1: поиск, который сайт увёл на свою категорию, читается там

Ветка: `claude/site-category-landing`. Версия worker: `2026-10-26.7`.
Сначала прочитай `.claude/plan/cold-path/PROTOCOL.md` из этой же ветки.

## Что видели (замер 26.10 на проде, 32 незнакомых сайта, worker 2026-10-26.6)

Строки `[site-api]` журнала eve:

- 4lapy.ru: операция `4lapy.ru/search/` (fit exact), прямое чтение — `moved` через 12,5 с.
- biggeek.ru: поиск строкой сайта (`via: box`) — `empty` за 13,7 с; позже выученная операция
  `biggeek.ru/catalog/%word%` — `moved` за 1,4 с.
- xcom-shop.ru: строкой — `empty` 14,3 с, названная моделью страница — `empty` 10 с.
- kant.ru: строкой — `moved` за 10,8 с (позже операция `www.kant.ru/search/` прочиталась за 1,8 с).

Запросы там — слова-категории («ноутбук», «корм для кошек», «палатка»). Похоже, сайт отправляет
такой поиск на свою страницу категории (`/catalog/noutbuki/`), а не на выдачу поиска. Для
html-операций это уже учтено (`site_rows_landed` + `site_rows_name_search`, запись про Петрович
«дрель» в dev-notes), а для операций `document`/`xhr` прямое чтение требует тот же путь
(`site_same_path` → `moved`), и поиск строкой, ушедший на категорию, может не найти карточек
(`empty`). Это гипотеза: сначала подтверди или опровергни её на стенде по этим сайтам (с выхода
США часть может не открыться — тогда локальная модель: страница поиска, отвечающая редиректом
на категорию, и категория с карточками).

## Что сделать

Поиск, который сайт сам увёл на страницу своей категории (тот же сайт по `site_same_place`,
путь глубже корня — главная никогда не выдача), отвечает карточками этой страницы, если они
называют слова запроса (правило `site_look_answers`: половина первых десяти), — и в прямом
чтении операции (`/v1/op`), и в поиске строкой сайта (`/v1/look` с `site`). Страница категории —
не повод считать операцию сломанной (`moved` уже не в счёт здоровья — проверь, что так и
останется) и не повод учить из неё операцию для всех запросов. Бро получает ответ так же, как
сейчас получает карточки взгляда (`from: "page"`, порядок сайта); если для этого нужен новый вид
ответа `/v1/op`, Бро должен принимать его только от worker не старше `2026-10-26.7`
(как `siteSearchingWorker` в `agent/lib/browser-vm/runs.ts`).

Не ломай: город hh.ru (`site_same_place` хостов), ozon (не трогаем вовсе), уход на чужой сайт
(`moved`), главная сайта, страница одного товара (поиск по точному названию уводит на товар —
это не выдача).

Проверка: тест, который падал до правки (локальная страница-редирект на категорию);
по возможности замер на стенде по 4lapy, biggeek, xcom-shop, kant — сколько ответили и за сколько.
