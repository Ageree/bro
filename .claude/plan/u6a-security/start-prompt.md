# U6a. Безопасность перед открытой бетой: частота кодов входа и web_fetch

Ты делаешь только этот юнит. Сначала — `.claude/plan/PROTOCOL.md`.

## Зачем
Бета открыта: регистрация без списка, любой номер получает аккаунт. Это
решение владельца, его не меняй. Аудит нашёл две дыры, которые открытость
делает опасными. Ограничений функционала пользователям не вводим.

## 1. Частота кодов входа
`sendOTP` (Better Auth, `db/services/auth/index.ts`) шлёт код в iMessage с
линии Бро. Свой лимит не настроен, поэтому любой может засыпать кодами чужие
номера, и линию iMessage заблокируют. Сначала выясни, какой rate limit
Better Auth действует по умолчанию на этом пути и есть ли он вообще на проде
(хранилище лимитов, IP за Caddy: заголовок `x-forwarded-for` — проверь, что
Better Auth берёт IP клиента, а не 127.0.0.1). Затем сделай лимит по номеру
(например, 3 кода за 10 минут и 10 в сутки) и по IP, с хранением в базе
(процессов два — web и eve). Сделай тест.

## 2. web_fetch и внутренние адреса
`agent/tools/web_fetch.ts` делегирует в `web_fetch` eve. Модель может получить
URL из письма или со страницы. eve и вход очереди мира слушают
`127.0.0.1:4274`, рядом deployd и метаданные облака `169.254.169.254`.
Прочитай `node_modules/eve/dist/...` и найди, режет ли eve приватные адреса
(включая редиректы и DNS, который резолвится в приватный адрес). Если не
режет — добавь проверку через существующий `fetchPublic`/`isPublicAddress`
(найди их). Покрой тестом `127.0.0.1`, `localhost`, `[::1]`,
`169.254.169.254`, `10.x`, редирект на приватный адрес. Проверь и другие
инструменты, которые сами качают URL из модели (`find_images`, вложения по
ссылке, `generate_image` и т. п.): перечисли их в PR и закрой очевидные.

## 3. Проверить и записать (без правок, если всё в порядке)
- `proxy.ts` пускает без сессии `/eve/v1/dev/schedules/dynamic`. На проде GET
  отдаёт 404. Убедись по коду eve, что dev-маршруты в продовой сборке не
  регистрируются. Если регистрируются — закрой.
- `localDev()` в `agent/channels/eve.ts` (principal `browser-benchmark`) не
  должен работать в проде: подтверди по коду.
