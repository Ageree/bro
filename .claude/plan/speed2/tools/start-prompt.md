# Единица «tools»: медленные инструменты в ходе человека (кроме браузера и Яндекса)

Ветка: `claude/speed2-tools` от `origin/bro-next`. Бюджет: 250 ₽.
Сначала прочитай `PROTOCOL.md`:
`git show origin/claude/speed2-plan:.claude/plan/speed2/PROTOCOL.md`.

## Задача — только эта

Найти инструменты, которые дольше всего держат человека до ответа, и ускорить 1–3
главных. Поведение и результат инструмента не меняются.

## Что известно

- Ход с инструментом идёт так: шаг 0 (~1,5 с с кэшем) → инструмент → шаг с
  `send_message`. Пилот `EARLY_REPLY_*` иногда шлёт короткое «сейчас поищу» до
  инструмента, но ответа человек всё равно ждёт до конца инструмента.
- `reply-latency.sh` (веб, с 15.10): ожидание p50 5,1 с, p75 8,1 с, p90 13,2 с. Хвост
  дают в основном ходы с инструментами.
- Замеры 11.10: yandex 6–11 с, yandex_purchase 15–23 с, phone-call 15 с. Яндекс,
  браузер и телефон — не твоя задача.
- `web_search` с 14.10 идёт через Composio Instant (TinyFish → Tavily → RouterAI),
  около 1 с. Длительности на проде не мерил никто.
- Google (Gmail, Календарь, Диск) идёт через прокси Composio
  (`agent/lib/composio/`, `agent/lib/google-workspace/`). При голом 403 GET
  повторяется через 3 с.
- Среди кандидатов есть ещё: память (`agent/lib/memory/`, recall), `route_time`
  (OSM, ограничитель на инстанс), `find_images`, `timepad_events`, погода и места.
  Посмотри по журналу, что вызывается чаще всего.
- Длительность каждого инструмента есть в строке `{"method":"EVE",…}` журнала eve:
  `ai.tools[].name` и `durationMs`.

## Что сделать

1. Собери длительности инструментов:
   - по журналу eve, все ходы, которые есть в хвосте журнала;
   - своими прогонами в аккаунте владельца, только чтение: найти что-нибудь в интернете;
     «что у меня завтра в календаре»; «есть ли непрочитанные письма от …» (только
     поиск и чтение); «сколько ехать от … до …»; «что ты помнишь о моих
     предпочтениях»; «какие мероприятия в Москве на выходных».
     Для каждого — хотя бы 5 повторов.
2. Таблица: инструмент → частота → p50/p90 длительности → откуда время (сеть до
   Composio/Google, повторы, последовательные вызовы, разбор).
3. Ускорь 1–3 главных: параллельные вызовы вместо последовательных, лишний круг по
   сети, повтор, который ждёт зря, кэш неизменных данных на ход. Отдай ответ раньше, не
   меняя его смысла. Таймауты не укорачивай так, чтобы появились отказы.
4. Если инструмент медленный из-за внешнего сервиса и сделать нечего — запиши цифры и
   причину в «не сделано».
