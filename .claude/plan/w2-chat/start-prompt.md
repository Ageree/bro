## Что нашёл координатор (прод, 18.10)

- `/chat` грузит **2,06 МБ JS** (585 КБ сжато), `/workspace` — 1,4 МБ, `/` — 0,75 МБ.
- История сессии уже читается страницами (`readLatestSessionHistory`,
  `readOlderSessionHistory` в `_lib/session-history`, хук
  `[sessionId]/_components/activity/use-session-history.ts`), но не проверено: размер
  первой порции, догрузка у верхнего края, перерисовки всего списка на каждый
  `message.appended` во время ответа, тяжёлые строки (markdown, подсветка кода) в
  длинном разговоре.

## Что сделать

1. Бандл `/chat`: `pnpm build`, найди крупнейшие модули маршрута (анализ чанков
   `.next`), вынеси тяжёлое и редкое в `next/dynamic` / ленивый импорт (рендер
   markdown/кода, карточки, вложения, геопозиция — что окажется крупным), убери лишние
   `"use client"` у того, что может быть серверным. Замер — байты JS маршрута до/после.
2. Длинный разговор (сгенерируй 500+ сообщений с markdown и кодом): число перерисовок
   строк при стриминге ответа (React Profiler или счётчик в тесте), мемоизация строк по
   id события, `content-visibility: auto` или виртуализация — выбери по замеру (время
   кадра/скрипта в Playwright-трассе локального dev/prod-сборки, размер DOM).
3. Ранние сообщения: размер первой порции, предзагрузка следующей у верхнего края
   (IntersectionObserver, без прыжка прокрутки), индекс/курсор на стороне eve-чтения —
   смотри, что делает `_lib/session-history` (читает поток событий eve по индексу).
   Если узкое место в eve — опиши, не патчи eve.
