### Роутер Jev для помощника и подпись без ask (PR #486)

- **Роутер Jev для помощника.** Флаг `TASK_KIT_ROUTER_WORKSPACES`. Решение принимается в
  `agent/lib/kit-router/`, блоки инструкций лежат в
  `agent/subagents/task/instructions/content/kit/`. На 42 настоящих заданиях полнота 52/52, в
  среднем помощник видит 54 % текста; без флага текст прежний, байт в байт.
- **Подпись.** У `prepare` больше нет `ask`: модель на анкете сама просила вопрос, хотя
  человек просил подписать. Дату, которую назвал человек, и расшифровку помощник вписывает сам
  (`sign.md`; «сегодняшнюю» Бро пишет помощнику числом).
- Закрыты пункты ревью 16.10: текст задания уходит в Jev очищенным, как у роутера
  инструментов (`cleaned`, тест: ни одно число от 4 цифр не доходит); ответ Jev без вероятности
  блока — все блоки; роутер слышит все сообщения после последнего услышанного (сообщение
  занятому помощнику); `seesFirst` ловит «перед подписью покажи», «дай я сначала гляну»,
  «хочу посмотреть»; «сам подпись не ставь» — в ядре набора; факты о данных называют Jev и для
  пилота роутера помощника; флаг снят в `tests/setup-env.ts`.

## Как гонять

- Фикстуры: `~/.bro-bench/files-venv/bin/python scripts/bench/files/fixtures.py`, после правки
  генераторов.
- Прогон: из чекаута `bro-next` с Node 24, только проблемные кейсы, строго по одному.
- Окружение для голосового кейса: `MODEL_PROVIDER=routerai`, `ROUTERAI_API_KEY` без
  типографских кавычек, заглушки `BETTER_AUTH_URL`, `BETTER_AUTH_SECRET`, `DATABASE_URL`, и
  через `env -u` снять `TELEGRAM_BOT_USERNAME IMESSAGE_PROJECT_ID OPS_ALERT_BOT_TOKEN
OPS_ALERT_CHAT_ID S3_ACCESS_KEY_ID S3_SECRET_ACCESS_KEY`.
- Команда: `BENCH_PYTHON=$HOME/.bro-bench/files-venv/bin/python pnpm bench run --suite files
--case <ids через запятую> --out ~/bench/files-N --background-wait-min 25`. Итог —
  `<out>/<кейс>/checks.json`.
- Цена кейса: `scripts/cloudru-app-host/host.py ops bro-app-sel-2 usage-stats.sh <начало> <конец>`
  по `startedAt`/`finishedAt` из `<out>/<кейс>.json` — строки `task` (помощник) и
  `interactive` (Бро); учитываются все воркспейсы, поэтому гоняйте ночью.
