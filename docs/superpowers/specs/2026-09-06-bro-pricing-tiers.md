# Тарифы Bro помимо 2000 ₽/мес

Расчёт от 6 сентября 2026, **правка в тот же день**: браузер пересчитан
по операторским цифрам Dev + Evomi, не по капу `BRO_BROWSER_MAX_COST=1`.

Курс ЦБ: **1 USD = 86,59 ₽** ($1 ≈ 87 ₽). Чеки в `solsav1703@gmail.com`
не нашлись. Inkbox / Convex / Vercel / OpenRouter / ЮKassa — с публичных
прайсов. Browser Use — с факта оператора (план Dev $29 кредитов на аккаунт,
Luna, Evomi PAYG $0.99/GB).

Сейчас в продукте один платный уровень: `BRO_PRICE_RUB=2000`, лимиты
500 сообщений/день и 60 браузер-задач/мес. Бесплатно: 30 / 5.
Биллинг ЮKassa умеет только одну сумму. Поля `plan` нет.

Лендинг и оферту не менять, пока ЮKassa не принимает выбранный план.

## Ошибка первого прохода

Я взял `maxCostUsd = 1` как **среднюю** цену джоба ($0.25–1.00) и нарисовал
дыру «60 × $1 = $60». Это стоп-кран одного run, не чек.

Факт на уже купленном Dev:

| | Dev + Evomi PAYG | Только Browser Use (сейчас: WB без прокси, Ozon/Такси RU $5/GB) |
|---|---|---|
| Токены + браузер (Luna) | $2.64 | $2.64 |
| Сеть | $0.71 | $1.56 |
| Обычный юзер, 20–25 джоб, ~0.6 GB | **$3.35** (~290 ₽) | **$4.20** |
| Потолок 60 джоб | **~$11** | ~$15 |
| Тихий | ~$1.50 | ~$1.75 |

Почти всё — Luna, не прокси. Evomi дешевле на ~$0.85 / юзер / мес
(~75 ₽, ≈ −20% на задаче). Пакет 100 GB в эту цифру не входит.

Dev — это **$29 кредитов на весь аккаунт**. Пока Cloud по всем людям
≤ $29, платишь $29 в любом случае. Evomi тогда просто +$0.99/GB сверху.

| Обычных людей | Счёт «только BU» | Dev + Evomi | Живые деньги |
|---|---|---|---|
| 1 | $29 | $30 | нет, −$1 |
| 5 | $29 | $32 | нет |
| 8 | $34 | $34 | ноль |
| 9 | $38 | $34 | да, ~$4 |
| 10 | $42 | $35 | да, ~$7 |
| 15 | $63 | $50 | да, ~$13 |

Правило: задача юзера ~$3.35 вместо ~$4.20. Окупается примерно с **9-го**
обычного человека. До этого Evomi почти не окупается.

Итого за джоб у обычного: **~$0.15**, не $0.35–1. Потолок 60 джоб —
**~$11 ≈ 955 ₽**, не 5 220 ₽.

## Прокси: где живые деньги

Цель «удешевить прокси» верная, но потолок узкий.

- У обычного сеть — **$0.71 из $3.35** (21%). Luna — 79%.
- Evomi vs текущий гибрид BU: **−$0.85 / юзер / мес**, если Cloud
  уже выше $29.
- До 9 обычных Evomi — надбавка к полу Dev.
- Пакет 100 GB: 100 / 0.6 ≈ **167 человеко-месяцев** обычных.
  На 15 людях это ~11 месяцев запаса. Не класть в юнит, пока нет
  стабильных 15+ и желания платить вперёд.

Следующий рычаг дешевле прокси — **короче Luna-run** (меньше шагов,
не гонять WB через RU-рез, стоп на капче). Evomi окупать с 9-го
человека, не раньше.

## Как продавать

- **Бесплатно** — попробовать чат. Без брифа и сторожей.
- **Лайт** — переписка и напоминалки, чуть браузера. Для тех, кому 2000 дорого.
- **Полный** — якорь. Обычный юзер как в расчёте Dev+Evomi.
- **Про** — worker, запас сообщений, «пишет первым». Не обещать личный
  E.164: на Startup dedicated iMessage **один на орг**.
