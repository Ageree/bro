# Финмодель Bro

`bro-finmodel.xlsx` — живые формулы; жёлтые ячейки — вводные (курс, цена, N, ₽/день токенов, цены единиц).

Выводы при цене 1 999 ₽, постоянных 69,7 тыс. ₽/мес (курс 84,41), номере на каждого:

- Токены 75–100 ₽/день (2 250–3 000 ₽/мес) больше самой выручки: при них 1 999 ₽ не окупается ни при каком N. Цена для нуля при N=200 — 3,1–3,9 тыс. ₽.
- Нуль при 1 999 ₽: ≈42 ₽/день токенов при N=200, ≈30 при N=100, ≈50 при N=500. Маржа 30% при N=200 — ≈22 ₽/день.
- Цена единиц в листе «Профили и лимиты» (голос, звонки, браузер) — допущения; сверять по `usage_costs` (`host.py ops <VM> usage-stats.sh`).

## Факт прода (`usage-stats.sh`, 26.10–02.11)

- Самое дорогое — длинная Telegram-сессия: контекст шага 100–390 тыс. токенов, 0,67 ₽/шаг против 0,14 ₽ в вебе. Это и есть «75–100 ₽/день» (один аккаунт ≈ 70 ₽/день).
- Поручение браузеру — в среднем 2,4 ₽ (p90 4,6), а не 15.
- Голос и звонки в `usage_costs` не пишутся: их цена остаётся допущением.
