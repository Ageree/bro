# Bro

Личный консьерж в iMessage и Telegram. **eve** крутит агента, **Convex** держит
тенантов, заказы и долгую память, **Photon Spectrum Pro** — транспорт iMessage,
**Inkbox** — почта и OTP. Полное описание продукта — в `README.md`
(намеренно без `@`-импорта: он на 30 КБ и съел бы контекст каждой сессии).

## Где что лежит

| Путь | Что там |
| --- | --- |
| `agent/` | Сам агент: `instructions.md` (голос и правила), `tools/`, `channels/`, `memory/`, `subagents/`, `skills/` |
| `convex/` | Бэкенд: схема, тенанты, `wakeups`, `watchers`, `orders`, `vault`, `instinct`, крон |
| `scripts/` | Все `*-check.ts`, `e2e.ts`, `deploy.sh`, фейковый Browser Use |
| `shared/` | Код, который нужен обеим сторонам (`vaultCrypto.ts`) |
| `.harness/goals/` | Журнал больших целей: `goal.md`, `events.jsonl`, `state.json` |
| `*.html` в корне | Лендинг, кабинет, сейф, оферта — деплоятся как статика |

## Команды

```bash
pnpm install --frozen-lockfile   # ставить только через pnpm (lockfile + CI)
npm run check                    # вся батарея проверок, ~10 с, параллельно
npm run check -- --only=onboard,silent   # сузить
npm run dev:local                # eve на :2000
```

- Node 24 (`.nvmrc`). TypeScript запускается напрямую: `node --experimental-strip-types`, отдельного шага сборки нет.
- `npm run check` — это `types:check` плюс каждый `*:check` из `package.json`. CI (`.github/workflows/checks.yml`) гоняет ровно её на каждый push и PR.
- `composio:check` в батарею не входит: ему нужен живой ключ и `.env.local`. Запускать руками.
- `npm run e2e` говорит с задеплоенным Bro. Локально его не гоняют — для этого есть `e2e:check`, который проверяет сам прогонщик без сети.

## Как здесь принято

- **Проверки до пуша.** `npm run check` зелёный — иначе PR красный на первом же коммите.
- **Новая логика — новый `*:check`.** Скрипты в `scripts/` — чистые утверждения над policy-модулями: без сети, без секретов, без деплоя. Это единственный тестовый слой, другого нет.
- **Комментарии объясняют «почему», а не «что».** Смотри шапки `scripts/check-all.ts` и `pnpm-workspace.yaml`: там записана причина, по которой код такой, а не пересказ строк.
- **Коммиты — по-русски, от симптома, который увидел человек**, а не от файла, который поменяли: «Ключ Browser Use с переносом строки внутри — fetch отказывался слать заголовок (#114)».
- **Константы вместо env там, где ошибка тихая.** Диапазон тестовых тенантов `+1555555` зашит в `convex/lib/testTenantPolicy.ts` намеренно: env-переменная в одном опечатанном символе от того, чтобы заглушить живых людей.
- Зависимости не добавлять без нужды: `minimumReleaseAge=0` и `allowBuilds` в `pnpm-workspace.yaml` настроены под конкретный набор, новый пакет с postinstall уронит установку в CI.

## Память между сессиями

Облачные сессии Claude Code одноразовые: контейнер забирают после простоя,
`~/.claude/projects/*/memory/` вместе с ним. Поэтому долгая память агентов
живёт в репозитории и ездит через git.

- `.claude/memory/MEMORY.md` — индекс: одна строка на вывод, грузится в каждую сессию (импорт ниже).
- `.claude/memory/*.md` — темы, читаются по требованию, когда индекс на них сослался.
- `.claude/hooks/session-start.ts` — на старте подмешивает свежее состояние: ветка, последние коммиты, активные цели из `.harness/goals`.

**Протокол.** Узнал что-то, что пригодится следующей сессии и чего не видно из
кода — допиши строку в `MEMORY.md` и закоммить вместе с работой. Подробности —
в отдельный файл темы, в индексе оставь ссылку. Держи индекс короче 200 строк:
устаревшее удаляй, а не копи. Не пиши туда то, что выводится из кода, и то,
что уже сказано в этом файле.
